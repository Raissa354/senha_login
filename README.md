## Resumo de como funciona

 Esse programa é uma **tela de login simples** que verifica se o usuário digitou o nome e a senha corretos.

 - O usuário informa um **nome de usuário** e uma **senha**.
- Ao clicar no botão **"Entrar"**, a função `verificarLogin()` é executada.
- O JavaScript pega os valores digitados usando `getElementById()`.
- O programa verifica se:
  - Usuário é **`login`**
  - Senha é **`1234`**
- Se os dados estiverem corretos, aparece **"Login feito com sucesso!"** na cor verde.
- Se estiverem incorretos, aparece **"Usuário ou senha inválida!"** na cor vermelha.
- O `console.log()` também mostra o usuário e a senha no console do navegador.

 ### Resumindo

 O **HTML cria a tela de login**, enquanto o **JavaScript verifica os dados digitados e informa se o login foi realizado corretamente ou não**.
